## 🌟 قابلیت‌های جدید اضافه شده:

### ۱. سیستم ورود و ثبت‌نام واقعی (User Authentication)
- امکان ثبت‌نام با **نام کاربری**، **رمز عبور** و **انتخاب استان**.
- ذخیره امن هش پسورد با الگوریتم رمزنگاری `SHA-256 + Salt` در دیتابیس Cloudflare D1.
- ثبت دائمی سوابق، رکوردهای سرعت و ریتینگ Elo برای هر کاربر.
- امکان بازی به صورت مهمان (Guest) بدون نیاز اجباری به ثبت‌نام.

### ۲. چالش‌های روزانه (Daily Challenges)
- هر روز یک **چالش اختصاصی ۲۵ سوالی** به صورت قطعی (Deterministic) و همسان برای تمام شرکت‌کنندگان سراسر ایران تولید می‌شود.
- رده‌بندی اختصاصی روزانه در جدول برترین‌ها (Leaderboard) برای رقابت عادلانه روی سوالات یکسان.

### ۳. یکپارچه‌سازی کامل موتور مسابقه (Unified Game Engine)
- حذف ساختار چندپارچه و باگ‌های سوییچ مود؛ اکنون تمام مسابقات در یک **استیج واحد، فوق سریع و بدون باگ** اجرا می‌شوند.
- امکان انتخاب آسان پریست‌های مسابقه قبل از شروع:
  - ⚡ **مسابقه ۳۰ ثانیه‌ای**
  - ⏱️ **ماراتن ۶۰ ثانیه‌ای**
  - 🎯 **چالش ۲۰ سوال**
  - ✖️ **تمرین جدول ضرب**
  - 💀 **حالت بقا (مرگ ناگهانی)**
  - 📅 **چالش روزانه**
  - ⚙️ **تنظیمات دلخواه (شخصی‌سازی عملگرها)**

### ۴. پاک‌سازی متون و نام‌گذاری حرفه‌ای
- حذف تمام اصطلاحات نامأنوس مثل «ضربخانه تخصصی» و عبارات فنی داخلی (مانند آی‌دی‌های هش، لاگ‌های سرور، کدهای پاپ و کلمات ماشینی).
- استفاده از نام‌های روان، رقابتی و جذاب فارسی.

## 🚀 راهنمای راه‌اندازی و دیپلوی

### اجرای لوکال و تست:
```powershell
cd f:\code\mathgame

# اجرای مایگریشن اسکیما روی دیتابیس لوکال
npm.cmd run d1:init:local

# اجرای ۲۵ تست یکپارچگی (Auth, Daily, Anti-cheat, Elo, Worker)
npm.cmd test

# اجرای سرور لوکال
npm.cmd run dev
```

### دیپلوی روی دیتابیس ابری کلودفلر:
```powershell
cd f:\code\mathgame

# اعمال جداول و تغییرات روی دیتابیس ابری
npm.cmd run d1:init:remote

# دیپلوی نهایی
npx.cmd wrangler deploy
```
